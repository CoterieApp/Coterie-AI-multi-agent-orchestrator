# Getting started with the private beta

## Request access

Visit **[offlinestudio.eu/coterie](https://offlinestudio.eu/coterie)** and request private-beta access. Access is granted separately; submitting a request does not provide an immediate download. Follow the instructions sent when your access is approved.

## Prepare your environment

- Use Windows 10 or Windows 11, 64-bit.
- Have Git available for the repository you intend to use.
- Install and authenticate the official coding CLIs supported by your beta build, following each provider's own instructions.
- Check account access, usage limits and any provider charges separately from Coterie's free beta.

Supported CLI versions and setup details can change between beta builds. Use the onboarding instructions supplied with your installer as the build-specific reference.

## Choose a first task

Start with a disposable repository or a project with a recoverable baseline. A useful task has a narrow scope, visible acceptance criteria and a check you can run, such as an existing test or build.

For example: change a form validation rule, update the corresponding test and review the resulting diff. Avoid using a first evaluation to rewrite a large production application.

## Follow the work

1. Open or create the project and describe the desired outcome.
2. Review the Architect's proposed task plan and dependencies.
3. Choose approval and automation settings appropriate to the project.
4. Follow implementation and review in the map or task board.
5. Inspect the diff, reviewer findings and check evidence before accepting the result.

Read [the workflow](workflow.md) for the role of each stage. If something fails, follow [troubleshooting](troubleshooting.md).
