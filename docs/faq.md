# Frequently asked questions

## What is Coterie?

A Windows workspace for planning, parallel implementation, independent model review and project checks across supported official AI coding CLIs.

## How do I get it?

[Request private-beta access](https://offlinestudio.eu/coterie). Approved testers receive installation and onboarding instructions. This repository currently contains documentation and selected images, not an installer.

## Is the beta free?

Access to the private beta is free. Provider account costs and usage limits remain separate. Future commercial plans have not been announced in this repository.

## Which operating systems are supported?

The current private beta targets Windows 10 and Windows 11, 64-bit. No macOS or Linux application release is announced here.

## Which coding tools can I use?

Coterie coordinates supported official CLIs. The product currently describes workflows involving Claude Code, OpenAI Codex and Antigravity. Confirm the supported versions and provider prerequisites in your build's onboarding instructions. A provider reference is not an endorsement.

## Does the app replace provider accounts or their limits?

No. Authenticate through the official tools using your own provider access. Their requirements, terms and usage limits continue to apply. Never post credentials in this repository.

## Does a local desktop app mean models run offline?

The desktop workspace is local. Model execution and connectivity depend on the coding tool and provider you select. Do not assume a cloud coding workflow works without a connection.

## Does independent review guarantee correct code?

No. Different models can still miss problems. Evaluate reviewer findings, test coverage, configured checks and the actual diff against your requirements.

## Can tasks run in parallel?

Independent tasks can run in separate Git worktrees within configured limits. Dependencies, provider capacity, quotas and project settings affect execution.

## Is Coterie open source?

The application source is maintained privately. This repository is the public documentation and feedback hub. See [RIGHTS.md](../RIGHTS.md).

## Can I build Coterie from this repository?

No application source or build toolchain is included here. GitHub's automatic source archives contain these public materials, not the desktop app.

## Where should I send feedback?

Use [Issues](https://github.com/CoterieApp/Coterie/issues/new/choose) for reproducible bugs and feature requests. Use [coterie@offlinestudio.eu](mailto:coterie@offlinestudio.eu) for access requests, private support and security concerns.
