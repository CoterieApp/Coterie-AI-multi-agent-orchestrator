# Public beta feedback priorities

We are collecting feedback on these parts of the beta:

- Planning clarity: scope, dependencies and acceptance criteria.
- Parallel work: understanding which task owns each change.
- Review quality: findings that are actionable and tied to requirements.
- Check evidence: clear differences between passed, failed and unavailable checks.
- Human control: understandable approval, pause, stop and automation behaviour.
- Onboarding: clear Windows and official CLI prerequisites.

These are feedback areas, not commitments to particular releases or dates. This document does not announce new platforms, integrations or pricing.

Use the feature-request form to describe your current workflow, the specific problem and the outcome you need. Maintainers can discuss and update priorities as the beta develops.
