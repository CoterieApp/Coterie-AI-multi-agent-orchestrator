# Public product assets

These selected images are already used in Coterie's public presentation:

- `coterie-banner.png`: brand and visual task map.
- `completion-report.png`: illustrative task workflow and completion report.

They contain demonstration project data. Keep assets small, descriptive and free of credentials, private paths, user projects or customer information. Update this inventory when adding or replacing an image.

Branding and images remain subject to [RIGHTS.md](../RIGHTS.md). Keep application builds and internal recordings outside this repository.

**For code changes, follow the project coding guidelines** supplied by maintainers and [maintenance rules](../docs/maintenance.md).
