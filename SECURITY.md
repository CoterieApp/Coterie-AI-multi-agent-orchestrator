# Reporting a security concern

Please report potential vulnerabilities privately to **[coterie@offlinestudio.eu](mailto:coterie@offlinestudio.eu)** with the subject `Coterie security report`.

Include:

- The affected Coterie build and Windows version.
- A description of the potential impact.
- Minimal reproduction steps using a disposable test repository where possible.
- Relevant evidence with credentials, customer information and private source code removed.

Do not post exploit details, tokens, personal data or sensitive logs in public issues. Do not test against systems, repositories or accounts you do not own or have permission to assess.

This project has no published bug-bounty program or guaranteed response time. If you are unsure whether a report is sensitive, use the private email first.
